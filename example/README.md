# route_simulator example

A small Material 3 Flutter app (English/Turkish, follows the device language) that shows a simulated GPS stream
without a map: route presets (points and an encoded polyline), constant/realistic speed, noise, signal loss,
jumps, a stop and looping; playback controls with seek and 1×/5×/20× speed; live stats, a track plot, a speed
chart, a log of recent fixes and GPX export.

```bash
flutter run
```

Türkçe: Harita gerektirmeyen küçük bir Material 3 demo. Simüle edilen konum akışını istatistik, iz çizimi, hız
grafiği ve son konumlar listesi olarak gösterir; GPX dışa aktarır. Cihaz dili Türkçe ise arayüz Türkçedir.
